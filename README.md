# Gridiron Legacy

Original browser-based College-to-Pro football career simulator.

## Play
The game is a static website contained in `index.html`.

## Current systems
Player creation, all major positions, difficulty, recruiting, star ratings, college offers and commitments, depth charts, weekly preparation, games, player development, stats, rankings, awards, NIL, transfer portal, draft evaluation, 32-team pro league, career history, and browser saves.

Built as an original football career simulation project.
